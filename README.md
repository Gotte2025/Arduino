# https://github.com/Gotte2025/Arduino.git

Coleccion de proyectos Arduino organizados por categoria.

## Estructura del proyecto

- **ALARMAMONO/** - Proyectos de alarmas monoxido de carbono
- **Auto_Cautivo/** - Proyectos de robotica y control de autos
- **WiFi/** - Proyectos con conectividad WiFi
- **Sensores/** - Proyectos con diferentes sensores
- Y mas...

## Como usar

1. Abre Arduino IDE
2. Ve a Archivo > Abrir
3. Selecciona cualquier archivo .ino de este repositorio
4. Conecta tu placa Arduino
5. Selecciona la placa y puerto correctos
6. Haz clic en Subir (Upload)

## Requerimientos

- Arduino IDE o compatible
- Librerias especificas segun el proyecto (ver comentarios en cada archivo .ino)

## Notas

- Algunos proyectos requieren librerias adicionales (DHT11, BMP280, etc.)
- Consulta los comentarios en cada archivo para informacion especifica
- Modificar la configuracion WiFi segun sea necesario
